# sell-point-to-buy-point · 抖音电商「卖点转买点」Skill

> 把商品资料（主图 / 详情页 / 文档 / 文本，任意形式）转成**可直接指导短视频拍摄的买点库** HTML 报告。每条买点含收益、证据、可展示角度、证据强度，并按**抖音内容侧数据表现**排序（Tier 1/2/3）。

---

## 一、它解决什么问题

商家手上的商品资料几乎全是「卖点」——参数、功能、设计语言（"6000mAh 大电池""增高5CM厚底"）。但用户掏钱买的是「买点」——具体得到的收益（"宿舍断电也能吹一整晚""穿上直接显高5CM，合照都上镜"）。

本 Skill 完成三件事：

1. **翻译**：把每个卖点翻译成"用户愿意掏钱的理由"（收益 + 证据 + 可展示角度）
2. **核验**：自动检索抖音同品类内容，看每个卖点在爆款内容里的数据表现（出现频次 + 互动量），区分「独立强调」与「捆绑提及」，并标注证据来源（本商品资料 vs 同品类内容）
3. **排序**：按「需求热度 × 竞争空隙」分 Tier 1/2/3，告诉内容团队**先打什么、用什么做差异、什么做信任底座**

饱和 ≠ 不能打：饱和恰恰说明需求被验证过，只是要拼表达。

## 二、安装

将 `sell-point-to-buy-point` 整个文件夹放入你的 Skills 目录（例如 `~/.agents/skills` 或 `workspace/.user_skills`），重启会话即可。之后对 AI 说以下话术即可触发：

- 「帮我把这个商品做买点库」
- 「卖点转买点」
- 「这个商品怎么做内容」
- 直接上传商品主图/详情页/文档/文本，并说「做买点库」

## 三、处理流程（四步）

| 步骤 | 动作 | 产出 |
|---|---|---|
| ① 提取卖点 | 按「功能 / 效果 / 情绪 / 信任」四类整理价值点，同赛道少见者打【差异化】标签。只提取，不翻译 | 结构化卖点清单 |
| ② 翻译买点 | 每条卖点转成买点，三要素：收益（说人话、写画面）+ 证据（凭什么信）+ 可展示角度（拍得到才算数）。标注证据强度：高=平台实时数据/官方明示；中=官方声明；低=口头宣称 | 买点库草稿 |
| ③ 内容侧核验 | 自动检索抖音同品类内容，统计每卖点出现频次、互动量、正负面信号；区分「独立强调」（标题/主线，权重高）与「捆绑提及」（顺带，权重低）；内容侧信号标注来源类型 | 热度信号表 |
| ④ 自检 + 排序 | 三红线自检（不说人话 / 没证据 / 拍不出来 → 重写）；按需求热度×竞争空隙分 Tier 1 数据验证核心 / Tier 2 有信号+竞争空隙 / Tier 3 支撑信任 | 带排序的买点库 |

**输出**：HTML 买点库报告，包含 Hero（商品信息+图）、一句话策略、排序依据说明、Tier 1→3 买点卡片（每条含收益/证据/可展示角度/证据强度/热度徽章）、内容侧信号区（新发现买点 + 风险避雷）、页脚来源说明。

- **12 个产品测试全部跑通**：9 个本地品牌产品（Kipling 双肩包、不莱玫行李箱、狗哥鞋垫、能适负离子风扇、兔力油污净/地板清洁剂/管道通/马桶泡泡粉、MSM 波士顿女包）+ 3 个抖音侧类目（空气炸锅、电动牙刷、每日坚果）
- **与已有人工报告对照**（4 个品牌）：买点从"场景化描述"升级为"收益画面 + 证据分级 + 三红线"；排序从专家主观打分升级为内容侧实测互动量；可拍性从叙事脚本细化到具体镜头；新增"未明示项降级待核验"防乱承诺机制
- **最有说服力的内容侧证据**（可溯源）：狗哥鞋垫本商品自发内容 10.4 万赞；不莱玫"暴力托运+楼梯滚落"55.5 万赞；电动牙刷老爸评测菌斑显色 18.8 万赞

### 已知边界（使用预期）

1. **输入完整度决定输出上限**：没有官方详情页时，证据强度最高到"中"，Skill 不编造本商品事实
2. **热度 / Tier 是排序建议，不是投放保证**：来自抖音内容侧信号（出现频次+互动量），是"需求被验证过"的代理指标
3. **内容侧新发现买点**（消费者高频提但资料没写的）标「待商家确认」，确认后再转正式
