# 卖点转买点 · 使用说明（学员版）

> 一句话：**把商家的商品资料，变成一张"抖音视频怎么拍"的作业单。** 你只需要会传文件、会说话，剩下的 AI 帮你干。

---

## 一、这个东西是干嘛的？

商家给你的资料，写的全是**卖点**——就是产品说明书上的话："6000mAh 大电池""增高5CM厚底"。

但顾客想听的是**买点**——买了它能得到啥："宿舍断电也能吹一整晚""穿上显高5CM，合照都上镜"。

这个工具帮你做三件事：

1. **翻译**：把"商家想说的"翻译成"顾客愿意掏钱的"
2. **摸底**：去抖音上看看，这些卖点哪个大家是真爱看（有真实数据，不是拍脑袋）
3. **排序**：排好拍摄顺序——先拍哪个、拿什么做差异化、什么当信任背书

## 二、怎么安装？（一次性，5 分钟）

1. 拿到压缩包 `sell-point-to-buy-point.zip`，双击解压，得到一个文件夹 `sell-point-to-buy-point`
2. 把这个文件夹，**整个**放进你的 skills 文件夹
   - 每台电脑位置不一样，一般是 `~/.agents/skills` 或 `workspace/.user_skills`
   - 找不到就让懂电脑的人帮你放一次，之后就不用管了
3. 重启你的豆包（关掉重新打开）
4. 完成。以后每次使用都不用再装

## 三、装完怎么用？（每次 3 步）

**第 1 步：上传商品资料**

- 打开豆包，直接上传商品的主图、详情页截图、产品文档、评价截图……什么形式都行，**越全越好**
- 只有主图？也照样能做，只是有些信息 AI 拿不准，会在报告里标出来

**第 2 步：说一句话**

- 输入「帮我做买点库」
- 或者直接说「卖点转买点」「这个商品怎么做内容」

**第 3 步：打开报告**

- 等 1~2 分钟，AI 会给你一份 HTML 报告，点开（浏览器打开）就是你的**拍摄作业单**
- 一个商品一份报告，想跑几个商品就跑几个

## 四、报告怎么看？（重点看三块）

**1. 先拍什么**

报告最上面会写一句"先打什么、用什么做差异、什么做信任"——直接照这个安排拍摄计划，不用自己猜。

**2. 每条买点卡**

每张卡片上有四样东西：

| 卡片内容 | 什么意思 | 怎么用 |
|---|---|---|
| 收益 | 顾客具体得到啥（说人话） | 口播稿照着念 |
| 证据 | 凭什么信（认证/销量/好评） | 拍的时候把证据拍进去 |
| 怎么拍 | 镜头怎么拍才拍得出 | 照着机位拍 |
| 优先级 | Tier 1 先拍 / Tier 2 做差异 / Tier 3 做信任 | 排拍摄顺序 |

**3. 风险提示**

抖音上对这类商品的吐槽点、差评点，拍的时候绕开，别踩坑。

## 五、常见问题

**Q：报告里的"待商家确认"是啥？**

A：AI 在抖音上看到很多人这么聊这个商品（比如"免系鞋带""透气"），但商家的资料里没写。拍之前先找商家确认是不是真的，**别乱说**。

**Q：只有主图、没有详情页，报告准不准？**

A：功能、场景类照拍没问题；但"好评率、检测报告、销量"这类信任信息，AI 编不出来，会标成"待补充"。把资料补齐后再跑一遍，报告就更完整。

**Q：我啥都不懂，能用吗？**

A：能。你只需要会两件事：上传文件、打字。判断和排序都是 AI 干。

## 六、小贴士

- **资料越全，报告越能直接拿去拍**：上传前把能找的资料都传上
- 报告里的排序来自抖音真实内容数据，但市场天天在变，正式开拍前可以再看看最近的热门视频
- 拿到报告后如果觉得哪条不对，直接跟 AI 说"这条再改改"，它会重新优化
