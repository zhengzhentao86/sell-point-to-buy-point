# S1 买点库 Schema（S2/S3/S4 共用）

输出字段先行定死，S2 人群卡、S3 场景卡、S4 组合器直接消费这套字段，不做格式翻译。

## 买点库字段

| 字段 | 定义 | 示例（骆驼女鞋） |
|---|---|---|
| buy_point_id | 买点编号 | BP-01 |
| selling_point | 原始卖点（商家想说的） | 增高5CM厚底 |
| benefit | 收益：用户具体得到什么（说人话、写画面，禁参数罗列） | 小个子女生穿上直接显高5CM，不用内增高也显腿长，合照拍照都上镜 |
| evidence | 证据：凭什么信（官方明示/量化数据/平台数据/内容侧信号，可核验） | 详情页明示增高5CM+光脚/穿鞋对比图；内容侧"矮子乐合集"8.5k赞 |
| shoot_angle | 可展示角度：短视频里具体怎么拍（拍得到才算数） | 同一机位光脚→穿鞋腿部对比切换 |
| evidence_strength | 证据强度：高 / 中 / 低 | 高 |
| heat | 内容侧热度：高 / 中 / 低（抖音内容侧核验结果） | 高 |
| tier | 排序档位：Tier 1 / Tier 2 / Tier 3 | Tier 1 |
| buy_point_status | 状态：推荐 / 候选（待确认） / 淘汰 | 推荐 |

## 口径定义

**证据强度**
- 高 = 平台实时数据 / 官方页面明示
- 中 = 官方声明但无第三方验证（量化数据来源为官方对比时如实标注）
- 低 = 仅口头宣称（直接淘汰或标记候选）

**热度（内容侧）**
- 高 = 该卖点在品类爆款内容中被反复**独立强调**（作为标题/主线），且关联内容互动量大
- 中 = 有信号但多属捆绑提及；或需求场景明确（如通勤、懒人）但互动量一般——细分刚需可给"中"，不因互动量低直接给"低"
- 低 = 几乎无内容信号

**证据来源标注（防误读）**
- 证据字段同时标注来源类型：`商品资料`（本商品事实）vs `同品类内容`（内容侧信号，非本商品事实）
- 本商品事实只能来自用户提供的商品资料；内容侧信号仅用于判断需求热度/竞争空隙/新发现

**Tier 排序 = 需求热度 × 竞争空隙**
- Tier 1 数据验证核心：热度高（饱和说明需求验证过，拼表达）
- Tier 2 有信号 + 有竞争空隙：痛点存在但竞品少占（含内容侧新发现，标"待商家确认"）
- Tier 3 支撑与信任：正品、背书、场景、标签类，做底座不引爆

## 内容侧信号（报告附加区）

- **新发现买点**：消费者高频提及但商品资料未写（如透气、免系鞋带）→ 升 Tier 2 候选，待商家确认后转正式
- **风险提示**：负面信号（差评点、唱反调科普、价格争议）→ 话术避雷建议
